# ShopZone

A modern e-commerce shopping platform built with React and Tailwind CSS.

## Features
- Product catalog with search functionality
- Shopping cart with localStorage persistence
- Responsive design for all devices
- ⚡ Fast performance with Vite

## Tech Stack
- React 18
- Tailwind CSS v4
- Vite
- Lucide React (icons)

## Getting Started

```bash
npm install
npm run dev
```
